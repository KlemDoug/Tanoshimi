# Tanoshimi

Projeto educacional com 30 funções, listas e dicionários em memória.

Execute: `python main.py`

Teste: `python testes/teste_fluxo.py`

Os `input()` e `print()` ficam no `main.py`; as funções de negócio recebem parâmetros e retornam dados. Isso preserva modularidade e permite que cada participante desenvolva uma função.
